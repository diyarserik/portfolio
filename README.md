# Портфолио видеографа

Одностраничный сайт без сборки: `index.html`, `style.css`, `script.js`.

## Языки
Сайт на трёх языках: қазақша (по умолчанию), English, русский. Переключатель в шапке, выбор запоминается в браузере.
Все тексты лежат в **script.js**: объект `TEXT` и поля проектов и услуг в виде `{ kz: "...", en: "...", ru: "..." }`. Язык по умолчанию задаёт `DEFAULT_LANG`.

## Что заменить
1. **script.js** — `SHOWREEL`, `EMAIL` и массив `PROJECTS` (название, тип, клиент, год, ссылка на видео, роли, описание).
2. Обложки необязательны: без них берётся превью с YouTube или Vimeo. Свою можно положить в **images/** (16:9, около 1600 px, до 300 КБ) и прописать в `thumb`.
3. **script.js** — `CLIENTS` (бегущая строка клиентов, сейчас там заглушки) и `SERVICES`.
4. **images/portrait.jpg** — твой портрет 3:4 для блока «Обо мне».
5. **script.js → TEXT** — имя, заголовок, тексты «Обо мне»; **index.html** — техника и ссылки на соцсети.
6. Необязательно: **assets/reel-preview.mp4** — немой фрагмент шоурила на 5–10 секунд. Он заменит абстрактный фон первого экрана и будет искажаться за курсором (до 10 МБ).

## Публикация на GitHub Pages
1. Создай репозиторий `username.github.io` (тогда адрес будет https://username.github.io).
2. Загрузи все файлы в корень: Add file → Upload files → Commit.
3. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу из пункта 1.

Видео храни на Vimeo или YouTube, не в репозитории: у GitHub лимит 100 МБ на файл.
